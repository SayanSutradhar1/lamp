# Lamp Adapters (`adapters/`)

Protocol adapters that bridge external runtimes (such as Node.js libraries like Mongoose or Prisma) to Lamp's `LMP1/LCB1` binary transport.

- [`node-ts/`](node-ts/README.md) — `@lamp/node-adapter` for serving `LampApp` contracts inside a Node.js process over `LMP1/LCB1` TCP & binary WebSocket.
