# Lamp Prebuilt Platform Binaries (`npm/`)

Platform-specific npm `optionalDependencies` packages distributing prebuilt `lamp_server` executables for zero-config `lamp serve` execution:

- `win32-x64/` — `@sayansutradhar1/lamp-app-win32-x64`
- `linux-x64/` — `@sayansutradhar1/lamp-app-linux-x64`
- `linux-arm64/` — `@sayansutradhar1/lamp-app-linux-arm64`
- `darwin-x64/` — `@sayansutradhar1/lamp-app-darwin-x64`
- `darwin-arm64/` — `@sayansutradhar1/lamp-app-darwin-arm64`
- `stage-binary.mjs` — Helper script to stage a compiled `lamp_server` binary into the matching platform package directory
